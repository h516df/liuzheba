# 长笔记首切片

- 档案、每一张照片/视频、作者各有独立长笔记。保留全部原短字段，不自动迁移或截断。
- 全屏多段编辑、可选标题、明确保存、返回留草稿、二次确认放弃草稿。标题200字符，正文100000字符，超长粘贴整体拒绝并说明，不静默丢字。
- 编辑内存由 ViewModel 持有，正文不进入 Bundle。输入后300ms持久化草稿；显示“草稿已存本机”才代表完成，返回会等待落盘。进程被强杀前未落盘的最后输入不能保证保留。
- 保存笔记与删除草稿是同一 SQLite 事务。保存时核对原稿版本；恢复/撤销恢复切库后旧编辑器的写入被generation校验拒绝。
- 全部笔记可搜索正式笔记与草稿；档案搜索可命中其档案/媒体/关联作者的正式笔记。解除媒体关联不删除笔记，全笔记页标注原关联已移除。
- 格式6备份包含正式笔记和草稿，可读取1–5旧备份。旧版App不能读取格式6，需同版或更新版恢复。外部自动保护复用同一清单。
- 不新增云服务、AI调用、HTML执行器，不改原图/视频，也不自动提取私人素材。

参考产品交互：[Quillpad](https://github.com/quillpad/quillpad) 的笔记/附件/搜索，[Markor](https://github.com/gsantner/markor) 的长文独立编辑，[Joplin](https://github.com/laurent22/joplin) 的本地笔记组织。只参考行为，无代码复制或新运行时依赖；Quillpad为GPL-3.0，不将其源码合入本Apache-2.0项目。

验证为合成资料的主机Android/Compose与真实SQLite测试，不等价目标手机键盘/进程强杀、覆盖升级验收。
