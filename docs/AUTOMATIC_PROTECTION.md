# 自动本机保护（实现与验收边界）

## 用户操作

首次在设置中启用，系统只需授予一个本机父目录的访问权。留册自动创建“留册自动保护”子文件夹，用户无需命名或手动创建文件夹。也可直接重新选择已有保护子文件夹。系统选择器请求本地位置，应用再次限制为 Android 本机 ExternalStorageProvider，拒绝网盘与 Android/data、Android/obb。

设置显示保存路径、当前状态、最近成功校验时间，以及重新选择/恢复、立即校验重试入口。档案首页显示简短状态。普通 App 内保存不等于外部保护：只有当前清单及所有引用原件读回校验完成才显示“已保护”。导入部分失败或尚未写入档案会持续显示“待核对”，不会把已成功的一部分伪装成全部成功；该标记随恢复版本保留。

重装/清数据后 Android 会移除授权，无法零交互自动找回。重新选择原位置后，应用发现已有恢复版本，让用户明确选择恢复或保护当前资料。恢复先完整校验、在新私有代际中构建，再切换资料；原资料保留，设置可撤销恢复。版本选择列表最多展示最近 100 个有效版本，逐个解析后只保留摘要，避免历史清单累积占满内存。更早文件仍保留。发现的版本清单本身已校验，但原件是否全部可用仍在恢复时逐一确认。

## 格式与安全边界

- 私有 SQLite/原件工作库继续保留。没有整体改写到 SAF，没有云服务、账号上传或所有文件权限。
- 外部目录按内容摘要复用原始媒体字节；修改文字只追加小型版本清单，不重打包/重拷全部视频。每次发布版本前仍读取并计算全部被引用外部媒体的 SHA-256，不信任大小/修改时间缓存。
- 带摘要的版本清单包含原有 Codec 格式、外观与可移植文件名映射。清单、媒体及总展开容量沿用 BackupLimits。失败/中断的文件不被认作有效版本；重试追加新文件，不覆盖唯一好版本。
- 自动处理合并短时间连续变更，单次执行，和 Store 变更共用一致性锁。较大资料库校验期间写操作可能等待；低端真机与大库性能尚需设备验收。
- 离开页面但进程仍存活时可继续；系统杀进程/强停后的任务在下次打开时重新检查并继续。没有宣称后台永不被打断，也没有用周期任务冒充立即保护。
- 自动保护不会删除用户原文件、历史版本、失败残留或其他用户文件。历史版本增长会占用空间；空间不足明确失败并保留最近好版本。
- 外部保护文件不加密，应用锁不保护外部目录；原件可能含拍摄位置。系统授权前有明确提示。保护在同一设备上，不能抵抗整机损坏/丢失。

## 验证方式

ProtectionStoreTest 使用真实 Store、SQLite 与合成 SAF DocumentsProvider。覆盖自动建目录、逐字节原件、文字变更不重拷、旧版本不变、权限撤销、部分写入、清单写入中断重试与幂等、同大小/同时间戳损坏、恢复后撤销、丢失原件不替换当前库、容量预检、重开保守状态、并发保存、连续草稿合并、导入关联前崩溃窗口、部分导入提示、清数据恢复提示、直接选择恢复子目录、拒绝云/私有路径。

ProtectionUiSnapshotTest 用 Android 35 Robolectric 原生图形渲染真实 Compose，验证未开启/已保护/失败状态及 320dp、200% 字号深色布局；ArchiveUiSnapshotTest 仍覆盖实际设置入口。所有数据为合成资料。图片为云端本地验收产物，不提交公开仓库。

没有实体手机/系统选择器、真实 SD 卡拔出/重装、真实相机视频/GPS 或正式签名升级验收。不得将此源码 PR 当作已发布安装包或真机验收通过。

## Android 依据

- [Storage Access Framework 与持久授权](https://developer.android.com/training/data-storage/shared/documents-files)：用户选择的非应用私有文档在卸载后保留；移动/删除目录可能使授权失效。
- [clearApplicationUserData](https://developer.android.com/reference/android/app/ActivityManager#clearApplicationUserData())：清数据会清除运行时/持久 URI 授权，因此恢复必须重新授权。
