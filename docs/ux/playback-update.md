# 播放与前台一键更新

此切片独立于作者档案闭环，不改变存储格式、媒体原件或备份关系。

## 播放

复用现有 Media3 播放器。用户的播放/暂停意图与进度、静音、倍速一起保存；生命周期暂停不会覆盖用户意图。播放器只在当前可见媒体且无覆盖层时存在，恢复还需处于 RESUMED。接入 Media3 音频焦点与耳机拔出处理；播放结束不因旋转重新播放。

移除占据全画面的任意方向拖动定位，保留有语义的进度条、前后 10 秒按钮、双击定位和长按倍速，减少与上下翻档案和系统返回冲突。

## 更新

未保存过偏好的用户默认开启前台限频检查；已有 false 值保持关闭。下载仍需主动点击，不后台自动下载安装。

点击立即更新后，下载、摘要/签名/版本等现有校验通过，若始终在同一段前台会话，直接衔接系统安装确认。离开前台撤销这次自动衔接，即使校验完成前已回来也不会突然弹安装。进程恢复仅显示已验证的待安装文件。缺少安装来源许可时明确提示，用户自行打开设置；不绕过系统确认。

系统安装界面返回不代表成功，只有重新读取实际已安装 versionCode 达到目标才显示成功并清理收据。取消安装仍可重试，文件校验失败不修改现有档案。成功状态不阻止之后按原节流策略检查新版本。

## 验收边界

针对会话测试使用合成 APK 字节与假安装环境，不执行真实安装；不能替代同证书旧版覆盖新版验证。真实设备旋转、音频焦点、耳机拔出、AppLinks 和系统安装仍需设备验收。
