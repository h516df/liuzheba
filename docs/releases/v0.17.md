## 中文更新说明

### 改进

- 标签成为默认整理与筛选入口，常用标签点一下即可选中；分类仍可选，已有分类不变
- 相册与拍照直接打开；在档案详情添加媒体无需先进入编辑、再保存整份档案
- 长按媒体直接开始多选，返回先退出多选；大字号下操作按钮可换行
- 自动保护的例行进度与成功不再反复打扰，失败、未完成导入和首次配置仍明确提示

### 修复

- 自动保护复制与校验不再长期占用资料读写锁，减少浏览和标签操作等待；保留完整回读校验
- 减少新增、改名和删除标签时的重复整库读写，搜索刷新时保留已有列表
- 减少视频导入时无用的图片解码和过密进度刷新；已有档案直接追加媒体时同步保留未完成草稿
- 修复媒体已保存但返回界面前取消的边界，避免编辑器状态遗漏新媒体

### 说明

- 沿用原包名、正式签名约定和 shicang 安装包前缀；覆盖升级请勿卸载或清除资料
- 资料结构与备份格式6不变，仍可读取格式1至5；备份未加密，同机目录不等于异地备份
- 自动保护在应用运行时执行，被系统中断后重新打开会继续尝试；不保证退出后的持续后台运行
- 单个视频仍最多6GB；本次不承诺真实手机导入速度，真实6GB视频、音轨及正式覆盖升级仍需本机验收

## 验收与限制

- 本批功能在 host 277 项及 API 35 模拟器 6 项测试中通过；版本元数据变更后需以同一最终 head 的现有 CI 结果为准。
- 模拟器使用合成小视频，不能替代用户手机的真实 6GB 视频、音轨、系统覆盖安装与保留数据验收。
- 自动保护只保证当前进程中的执行与重新打开后的重试；不能从已删除的两份本机副本恢复，也不等于异地备份。
- 导入仍采用既有忙碌操作模型；本批不宣称所有文件操作都可无等待并发，分享/下载来源也未整体改为直接追加路径。
