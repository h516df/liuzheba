# 留着吧 v0.23 · 作品收藏的第一步

本版着重把“链接下载 → 建档案 → 再收录”简化为“分享或粘贴链接 → 下载并自动保存”。

- **一篇作品完整保存**：同批次媒体按原顺序归属同一篇作品，保留标题、文案、来源平台、作品链接和可靠作品 ID。重复保存同一作品时复用原作品、避免重复媒体；未下载成功的文件保留独立失败记录。
- **自动收录**：默认解析并下载全部可用媒体；完成或失败的批次自动保存已下载的内容，支持“先预览”再选择媒体。完成后无须创建档案或点击第二次保存。
- **作者自动归集**：小红书、抖音沿用严格身份规则；新增哔哩哔哩数字 MID、Instagram 数字 PK 自动归集。Instagram 用户名只作显示和主页跳转，不用于自动合并不同作者。
- **更自然的界面**：「我的」采用双列作品墙，顶部不再常驻档案/笔记/作者切换；它们在可选菜单中。发现页保持全屏上下刷、临时筛选，视频缓冲时保留封面。
- **可靠性**：保留旧 SQLite schema1、备份 format6 和媒体原件路径；可选下载数据损坏不隐藏现有任务；网络失败与平台限制分别提示。

## 已知限制

- 快手目前没有经过验证的专用下载提取器；一些链接仍可能无法解析。Instagram 图集依赖平台公开 API 或可用网页会话，平台限流和登录限制不能保证绕过。
- 抖音、小红书、Instagram 的旧回归链接存在过期、需登录或当前云端网络证书校验等限制；合成解析测试不能代替手机真实下载。
- 发帖编辑器仍使用兼容旧数据的统一编辑页面；完整无档案化发帖视觉、底部实时背景模糊和复杂视频预加载尚未完成。
- 官方同签名模拟器覆盖升级不代表用户手机已有媒体及实际安装版本已验收。

**覆盖升级**：正式 APK 应由原 `dev.h516.shicang` 证书签发，versionCode 从 23 递增到 24。请保留旧应用与资料，勿通过卸载解决安装冲突；有重要数据时先从设置导出完整备份。
