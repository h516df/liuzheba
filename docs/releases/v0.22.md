0.22 让「发现」更接近刷收藏作品的体验，同时把可信的社交作者资料串成可整理的档案。

- **发现页混合刷**：进入即混合查看已收藏的照片和视频，不再需要先选择分类。小红书等来源的纯图片作品作为一组图文翻看；其他旧档案里的不同媒体按作品逐条浏览。全部原始文件仍属于原档案。
- **可选筛选**：通过发现页更多菜单按视频、图片或现有档案分类临时筛选，恢复全部后继续混刷；筛选不会更改档案分类。
- **作者自动归档**：从小红书、抖音作品取得明确的原平台作者 ID 后，新建或复用作者卡，并自动关联到新建/已有的收录档案；在「档案 → 作者」点「查看珍藏」即可集中浏览这位作者的作品。仅凭昵称不会建立对应关系，既有作者资料、草稿及手动关联保持不变。
- **小红书链接**：在可信短链跳转到平台 `/404` 页、但仍带有合法笔记 ID 时，尝试恢复同平台作品地址重新解析；不会绕过登录、权限或访问限制。
